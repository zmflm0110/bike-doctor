240초 근처에서 정밀도가 정점(54.4%)을 찍고 평평해진다 → **"3분 안·300m 안"** 을 유지(정점과 0.3%p 차, 설명이 쉬움).
경보는 두 단계로: **노랑 = 서로 다른 사람 2연속(정밀도 약 52~60%)**, **빨강 = 3연속(약 70%)**.
